288: #### Create a new dynamic secret
289: 
290: Creating a new dynamic secret can be done by using the `.dynamicSecrets().create({})` function. More details below.
291: 
292: 
293: The input for creating new dynamic secret varies greatly between secret types.
294: For a more in-depth description of each input type for each dynamic secret type, please refer to [our API documentation](https://infisical.com/docs/api-reference/endpoints/dynamic-secrets/create)
295: 
296: 
297: ##### Example for creating a new Redis dynamic secret
298: 
299: ```typescript
300: import { InfisicalSDK, DynamicSecretProviders } from "@infisical/sdk";
301: 	const client = new InfisicalSDK();
302: 
303: 	await client.auth().universalAuth.login({
304: 		// For localhost
305: 		clientId: "CLIENT_ID",
306: 		clientSecret: "CLIENT_SECRET"
307: 	});
308: const dynamicSecret = await client.dynamicSecrets().create({
309:   provider: {
310:     type: DynamicSecretProviders.Redis,
311:     inputs: {
312:       host: "<redis-host>",
313:       port: 6479,
314:       username: "<redis-username>",
315:       password: "<redis-password>", // Only required if your Redis instance uses authentication (recommended)
316:       creationStatement: "ACL SETUSER {{username}} on >{{password}} ~* &* +@all",
317:       revocationStatement: "ACL DELUSER {{username}}"
318:     }
319:   },
320:   defaultTTL: "1h",
321:   maxTTL: "24h",
322:   name: "dynamic-secret-name",
323:   projectSlug: "project-slug",
324:   environmentSlug: "dev"
325: });
326: console.log(dynamicSecret);
327: ```
